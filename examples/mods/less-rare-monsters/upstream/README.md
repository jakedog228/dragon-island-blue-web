# Less Rare Monsters

This is a manifest-format mod for a Dragon Island Blue Mod Launcher.  It changes only the selected monsters' random-encounter weights. Dragons have approximately a 0.625% encounter chance, Iron Sludge approximately 8%, and Kappa and Cherub approximately 5% at each listed POI.

## Modified encounter locations

| Monster | World | POI |
|---|---|---|
| Water Hatchling | Southern Alvalon (`World_1-1`) | Charles' Hut (`1-1_Turtorial_Hut_2`) |
| Cherub | Southern Alvalon (`World_1-1`) | `Breeder_Hut_2` |
| Red Dragonling | Ringfeld (`World_1-3`) | `1-3_Forest_1` |
| Iron Sludge | Western Gracia (`World_2-1`) | `2-1_Forest_1` |
| Iron Sludge | Western Gracia (`World_2-1`) | `2-1_Forest_2` |
| Iron Sludge | Western Gracia (`World_2-1`) | `2-1_Forest_4` |
| Kappa | Safaris (`World_2-3`) | `2-3_Field_5` |
| Iron Sludge | Safaris (`World_2-3`) | `2-3_Forest_1` |
| Kappa | Norwoods (`World_2-4`) | `2-4_Field_1` |
| Gold Dragon | Eastern Gracia (`World_3-1`) | `3-1_Field_3` |
| Iron Sludge | Eastern Gracia (`World_3-1`) | `3-1_Field_4` |
| Iron Sludge | Eastern Gracia (`World_3-1`) | `3-1_Field_5` |
| Iron Sludge | Eastern Gracia (`World_3-1`) | `3-1_Field_6` |
| Iron Sludge | Eastern Gracia (`World_3-1`) | `3-1_Forest_1` |
| White Dragon | South Earlsome (`World_3-3`) | `3-3_Forest_4` |

The percentage is conditional on a random encounter occurring at that POI. It
accounts for the number of monsters generated in an encounter.

The mod does not alter fixed encounters, bosses, quests, dungeons, the Abyss,
game assets, executables, or save files.
